# Сборщик афиши «Клубок»

Раз в сутки собирает детские события Белграда из открытых источников и пишет `../data/events.json`.
Сайт (`Клубок — события для детей в Белграде.dc.html`) читает этот файл при загрузке; если файла нет
или он пустой — показывает встроенную демо-афишу.

## Локальный запуск

```bash
cd collector
npm install
npm run collect
```

Внешних зависимостей нет — все источники читаются обычным `fetch`.

## Что откуда берётся

| Источник | Как | Что может сломаться |
| --- | --- | --- |
| `instagram.com/p/…` | публичная страница `/embed/captioned/`: подпись + превью. Если задан `IG_OEMBED_TOKEN` — сначала Graph oEmbed | инстаграм меняет разметку эмбеда или закрывает пост; тогда источник помечается `error` в отчёте |
| `reg.prodlenka.me/schedule` (Продлёнка + Kinder Garden) | публичный REST base44 без авторизации: справочники `Location` и `Class` (название с возрастом, описание, цена, длительность, фото) джойним с `Schedule` (дата, время, занятость мест) и `getBookedCounts`. Каждое проведение из расписания на ближайшие `horizonDays` (28) дней → отдельное событие; площадка выбирается по `locationSlug` в `sources.json`. Сейчас расписание заполнено только для Kinder Garden | смена `appId` в URL API, переименование сущностей/полей base44 или slug'ов площадок |
| `enterspace.rs/classes` | статичный Tilda-сайт: со страницы `/classes` собираем ссылки на занятия, с каждой страницы регулярками вытаскиваем день/время («Когда»), возраст и время из `<meta name="description">`, цену и первое реальное фото | сайт банит IP при частых запросах подряд (между страницами пауза 800 мс); смена вёрстки Tilda-блоков сломает метки-якоря («Контакты», «Когда», «Разовое занятие —») |
| `math-line.ru/beograde/reg` (Sreda Kids + Mathline) | статичный Tilda-сайт с виджетом табов (T395): расписания обеих локаций уже есть в HTML одной страницы, просто скрыты CSS — по `data-tab-number` в `sources.json` находим нужный `data-tab-rec-ids` и парсим строки вида `ЧЧ:MM-ЧЧ:MM Название (возраст)` только под заголовками пн/вт/ср/пт/сб (чт и вс пропускаем по договорённости) | смена вёрстки табов T395 или переименование дней недели/заголовков-стопов («Продленка в MathLine», «Продлёнка Weekend») |
| `t.me/<канал>/<id поста>` (Индиго) | публичный embed-виджет поста (`?embed=1&mode=tme`) отдаёт текст без логина, даже если сама группа закрыта; текст — расписание по дням недели, строки вида `ЧЧ:MM Название возраст` | студия редактирует один и тот же пост при смене сезона (сейчас «летнее расписание») — если сменят формат строк или уберут заголовки дней недели, парсер перестанет находить события |
| `beopinokio.rs/reg` (ЛаборатоРиЯ) | статичный Tilda-сайт: расписание лежит в форме записи как чекбокс-группы по дням недели (`t-input-title` = «Понедельник» … «Воскресенье»), внутри `<input type="checkbox" value="ЧЧ.ММ Название возраст">`. Берём value чекбоксов под заголовками-днями, одно занятие в несколько дней склеиваем по «заголовок+время». Индивидуальные занятия (`/индивидуальн/i`) не берём по договорённости | смена вёрстки формы Tilda (классы `t-input-group` / `li_title__…`), переименование дней недели или перевод расписания в другой блок |

Картинки скачиваются в `data/images/` — CDN-ссылки инстаграма подписаны и умирают через несколько дней.

## Схема события

```json
{
  "id": "9f1c2b…",
  "title": "Лесной клуб на Ада Циганлии",
  "short": "Строим шалаши и завариваем чай",
  "desc": "полный текст источника",
  "date": "2026-08-22",        // разовое событие
  "wd": [0,2,4],               // либо еженедельное: 0 = понедельник
  "time": "11:00",
  "dur": "3 часа",
  "place": "Ада Циганлия",
  "address": "Вход у велодорожки",
  "age": [4, 10],
  "ageLabel": "4–10 лет",
  "price": "бесплатно",
  "image": "data/images/ig-DZuvdMejdSV.jpg",
  "source": { "name": "Instagram", "kind": "Инстаграм-пост", "url": "https://…", "cta": "Открыть пост в Instagram" }
}
```

## Добавить источник

1. Допишите объект в `collector/sources.json` (`type`: `instagram`, `prodlenka`, `enterspace`, `mathline` или `telegram`).
2. Для источника нового типа — файл в `collector/sources/`, экспортирующий `collect…(source, now)` и возвращающий события через `normalize()`, и строка в `RUNNERS` в `index.mjs`.

Разбор текста (дата, время, возраст, цена) живёт в `collector/lib/text.mjs` — правила русскоязычные, дополняйте по мере появления новых формулировок.

## Автосбор

`.github/workflows/collect.yml` — cron каждый день в 04:10 UTC + запуск руками. Коммитит `data/`, если файл изменился.
Модерации нет: всё собранное публикуется сразу. Отчёт по каждому источнику — в `data/events.json` → `report`,
и в логах Actions (`console.table`).

### Отчёт в Telegram

Если в секретах репозитория заданы `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`, после каждого прогона
`collector/lib/notify.mjs` шлёт в этот чат текстовое сообщение: список площадок с числом собранных
событий, общий итог и ошибки. Только уведомление — ни кнопок, ни команд. Без секретов шаг молча
пропускается (локальный запуск ничего не отправляет). Бот и chat_id — те же, что у функции
`supabase/functions/suggest-event` (см. её README, шаги 1–2).

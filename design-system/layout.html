Сетка и адаптив

Каркас

  • Страница — колонка на всю ширину: шапка 72px → заголовок раздела → лента дат (прилипает) → блоки → подвал.
  • Поля по бокам — page-gutter 28px; на телефоне — page-gutter-mobile 16px.
  • Между блоками главной — space-48 сверху у каждого заголовка блока.
  • Расписание кружков: лента слева, панель фильтров 288px справа, между ними space-56. Панель липкая.
  • Страница события: две колонки — текст 638px и правая колонка 426px (фото + карточка цены), между ними 80px, по вертикали 40px; максимум 1200px по центру.
  • Площадки: список 480px слева, карта справа на всю высоту.

Точки перелома

  • ≤1200px — панель фильтров превращается в строку чипов, лента на всю ширину.
  • ≤1100px — блок «Все ближайшие события» — 3 колонки.
  • ≤900px — страница события в одну колонку (заголовок → фото и цена → описание), подборки «Другие события» скроллятся вбок по 224px.
  • ≤760px (телефон) — бургер вместо меню, поля 16px, заголовки переносятся, одна колонка карточек, в списке скрываются миниатюры и колонка места, окна прижимаются к краям с отступом 10px.
  • ≤480px — подсказки (info-tip) выравниваются по правому краю.

Адаптив на сайте сделан через data-*-атрибуты с !important-правилами в общем <style> (см. components/bundle.css): разметка одна, правила переключаются по ширине.

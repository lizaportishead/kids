DatePicker

открыть отдельно ↗

Окно выбора дат на странице «Все ближайшие события»: быстрые кнопки «Сегодня / Завтра / Выходные» и календарь месяца.

  • Выбранные края диапазона — accent, дни внутри — accent-wash (#e8f5d8).
  • Прошедшие дни — icon-idle, выходные в заголовке недели — brand.
  • Точка под числом: brand-deep — в этот день есть события.

FilterChips

открыть отдельно ↗

Строка чипов-фильтров над подборками: «Любой возраст», «Все категории / типы», «Все районы», «Любой язык» (+ «Любая дата» на странице всех событий). Клик по чипу открывает окно одного фильтра (FilterModal).

  • Чип по умолчанию — пилюля на surface-chip (#f1ede4), 13px, стрелка вниз 12px.
  • Выбранный чип — рамка и заливка accent, в подписи значение («3, 4, 5 лет», «26–27 сентября»), рядом круглая кнопка сброса.
  • Строка скроллится горизонтально без полосы прокрутки.

FilterModal

открыть отдельно ↗

Окно одного фильтра — открывается по клику на чип. Белая карточка шириной до 460px поверх затемнения overlay.

  • Заголовок 22px/800 + круглая кнопка ✕; внизу основная кнопка «Готово».
  • Возраст — сетка круглых чипов 0–17 и «Все»; выбранные — accent.
  • Тип, район, категория — список строк-чекбоксов.
  • Язык — три пилюли: «Все», «Русский», «Сербский».

FilterRail

открыть отдельно ↗

Липкая боковая панель фильтров расписания (справа от ленты, ширина 288px). Видна при ширине экрана больше 1200px, ниже сворачивается в строку чипов.

  • Поиск по названию сверху; группы «Возраст», «Язык события», «Категория», «Район».
  • Возраст — круглые чипы 34px (выбранные зелёные accent), «Показать все (N)» раскрывает старшие возрасты.
  • Категории и районы — строки-чекбоксы (data-check-row), наведение — surface-hover-warm; квадрат чекбокса зелёный с белой галочкой.
  • Ссылки «Показать все» — accent-link (#6a8f3c), подчёркнуты.
  • Панель — рамка line-rail, радиус radius-xl (16px), внутренние поля 20px.

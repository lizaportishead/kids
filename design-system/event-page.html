  • Строка даты — 22px/800, brand. Для разовых — «Суббота, 26 сентября · 10:00», для постоянных — «по понедельникам и четвергам в 10:30».

PriceCard

открыть отдельно ↗

Правая колонка страницы события: большое фото (радиус 24px) и липкая карточка цены.

  • Карточка: рамка line-soft, радиус 20px, поля 22px, тень shadow-card.
  • «Цена» — подпись-атрибут, сумма 22px/800. Кнопка записи — основная крупная.
  • Под кнопкой — источник информации 12px muted.

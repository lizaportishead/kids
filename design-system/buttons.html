Button

открыть отдельно ↗

Кнопки сайта — всегда пилюли (radius-pill, 999px). Три вида по весу.

  • Основная — заливка brand (#ff6032), текст on-brand (#fff6ec), 15px/700 (16px в карточке цены). Одна на экран: «Добавить событие», «Отправить», «Записаться…», «Показать N событий».
  • Контурная — прозрачный фон, рамка 1px line-control, текст ink, 15px/500. Для вспомогательных действий: «Сегодня», «Календарь», «Назад…». Вариант 700 — «Смотреть все N занятий» под подборками.
  • Второстепенная в форме — контурная, текст ink-soft, 600 («Отмена»).
  • Закрыть — круг 40px на surface-sunken с глифом ✕.
  • Пункты меню шапки — пилюли без рамки; активный отличается только весом 700.

Контраст: on-brand на brand ≈ 2,9:1 — ниже 4,5:1 для 15px текста (так на сайте, см. README).

FavButton

открыть отдельно ↗

Сердечко «В избранное». Избранное хранится только в браузере (localStorage).

  • На карточке: круг 34px в правом верхнем углу фото, подложка rgba(255,255,255,.92), тень shadow-float, контур сердца icon-idle.
  • На странице события: круг 44px с рамкой line-control, сердце 22px.
  • Включено: сердце залито danger (#ff3b30); после клика снизу появляется Toast.

LanguageSelect

открыть отдельно ↗

Переключатель языка интерфейса в шапке — нативный <select> без рамки со стрелкой-картинкой. Переводится только интерфейс; тексты событий остаются на языке источника.

ViewToggle

открыть отдельно ↗

Сегментный переключатель вида расписания: плитка / список. Состояние сохраняется, ссылка ?view=list открывает список.

  • Две кнопки 42×32 в общей пилюле; выбранная — зелёная accent.

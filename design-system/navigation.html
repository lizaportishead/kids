BackButton

открыть отдельно ↗

Кнопка возврата на страницах события, занятия и площадки; рядом справа — круглая кнопка избранного 44px.

  • Контурная пилюля: рамка line-control, 15px/500, иконка-шеврон 16px.
  • На странице «Все ближайшие события» вместо кнопки — лёгкая ссылка «‹ Афиша» без рамки.
  • Состояние избранного: серое сердце icon-idle → залитое danger (#ff3b30).

Footer

открыть отдельно ↗

Подвал: дата последнего обновления расписания, ссылка «Обратная связь» и плашка-рекомендация Telegram-канала.

  • Тот же градиентный фон, что у шапки, сверху линия line-footer.
  • Текст 13px muted; ссылка «Обратная связь» подчёркнута (offset 2px).
  • Плашка канала — белая карточка с радиусом radius-sm (8px) и аватаркой 36px.

Header

открыть отдельно ↗

Шапка сайта: логотип-клубок с подписью, три раздела, переключатель языка интерфейса, сердечко «Моё избранное» и оранжевая кнопка «Добавить событие».

  • Фон — фирменный радиальный градиент (header-glow-green → header-glow-mist → header-glow-sun поверх surface); тот же градиент у подвала.
  • Пункты меню — пилюли без фона, ink-soft, 15px. Текущий раздел выделяется только весом шрифта (700 вместо 500), без подчёркивания и заливки.
  • Высота 72px, поля page-gutter (28px) по бокам.
  • При ширине ≤760px меню, язык и кнопка скрываются, появляется бургер ☰ — см. MobileHeader.

WeekdayTabs

открыть отдельно ↗

Вкладки дней недели в блоке «Постоянные занятия» на странице площадки.

  • Выбранный день — зелёная пилюля accent с тёмным текстом; остальные — контурные.
  • На узких экранах полные названия («Понедельник») заменяются сокращениями («Пн») через data-wd-full / data-wd-short.
